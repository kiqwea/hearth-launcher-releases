# Hearth Launcher

Быстрый и чистый лаунчер Minecraft: ник, версия, «Играть».

**[Скачать установщик](https://github.com/kiqwea/hearth-launcher-releases/releases/latest/download/HearthLauncherSetup.exe)**. Он сам скачает последнюю версию и проверит её подпись.

- Вход без лицензии по нику; Microsoft — скоро.
- Любая версия игры, Java ставится сама.
- Fabric, Forge, NeoForge и моды с Modrinth прямо в лаунчере.
- Sodium + Iris вместо OptiFine: больше FPS и шейдеры.
- Обновляется сам.

Если Windows покажет «Windows защитил ваш компьютер»: «Подробнее» → «Выполнить в любом случае».

Нужен свой сервер для друзей? [Hearth](https://github.com/kiqwea/hearth/releases/latest).

Здесь лежат только установщики и файлы обновлений.
